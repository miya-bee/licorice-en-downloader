Licorice EN Downloader v0.1.1 (development build)

Extract this whole ZIP, then run LicoriceENDownloader.exe.
You don't need to install Python. Settings are saved next to the EXE.
The UI follows the Windows display language (English or Japanese).
To change it: Settings > 表示言語 / Language, then restart the app.

1. After launch, check the release info from the official API and the destination.
2. Click "Download BIN".
3. Wait until the status reads "Downloaded and verified".
4. Click "Open folder" to find the verified BIN.

For details, open docs/en/index.html or click "Manual & install guide" in the app.

Rescue OS (release article by its author "E", in Japanese):
https://note.com/ample_zephyr2723/n/necd67d1bccb3
See the download section of the article. Chapter 5 of the manual covers preparation.

Target: X4 Pro / Licorice EN build
Unofficial tool. It does not write to the device or change its region setting.
Installing the BIN produced by this app from Rescue OS has not been tested on a real device.
